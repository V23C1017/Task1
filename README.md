# Task1

ロボットシステム学の課題で作成したソフトウェアパッケージを公開しています。

## access100コマンド

![test](https://github.com/V23C1017/Task1/actions/workflows/test.yml/badge.svg)

ディレクトリ配下で最近アクセスされたファイルを、最終アクセス日時が新しい順に一覧表示するコマンドです。

## 必要なソフトウェア

Python
  - テスト済みバージョン: 3.10〜3.14



## テスト環境

Ubuntu 24.04 LTS



### インストール方法

以下のコマンドを実行してリポジトリをクローンし、実行権限を付与します。

```bash
$ git clone git@github.com:V23C1017/Task1.git
$ cd Task1
$chmod +x access100
```
こちらで使用可能になります


## 使用方法

以下のコマンドで実行でき、最近アクセスされたファイルを最大100件表示します。
```bash
./access100
```
